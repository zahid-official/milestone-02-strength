## 🎯 Overview

**Strength** is a comprehensive fitness website that aims to make fitness accessible to everyone, regardless of income or gym access. The platform offers free workout videos, expert training guidance, BMI calculation tools, and flexible pricing packages to suit different fitness goals and budgets.

## ✨ Features

- **🎨 Modern UI/UX** - Clean, professional design with smooth scrolling and intuitive navigation
- **📱 Fully Responsive** - Seamlessly adapts to all screen sizes (mobile, tablet, desktop)
- **🏋️ Workout Library** - Access to 500+ free workout videos and 350+ video tutorials
- **🧮 BMI Calculator** - Interactive calculator with activity factor considerations
- **👥 Team Showcase** - Meet professional trainers with detailed profiles
- **💰 Pricing Plans** - Three flexible membership tiers (Starter, Premium, Elite)
- **🖼️ Rich Media Gallery** - High-quality images showcasing exercises and training

## 🛠️ Technologies Used

- **HTML5** - Semantic markup for better structure and accessibility
- **CSS3** - Advanced styling with:
  - Flexbox & Grid layouts
  - Custom animations and transitions
  - Media queries for responsiveness
  - Modern color schemes and gradients
- **Google Fonts** - Typography enhancement
- **GitHub Pages** - Deployment and hosting

## 🎨 Key Sections

### 1. **Hero Section**
   - Compelling headline with call-to-action buttons
   - Eye-catching banner showcasing fitness transformation
   - Quick stats highlighting platform benefits

### 2. **Change Your Habits**
   - Four core principles: Movement, Time, Practice, Weight Loss
   - Icon-based visual representation
   - Motivational messaging

### 3. **Run Extra Mile**
   - Feature highlight with engaging imagery
   - Mission statement emphasizing inclusivity
   - Call-to-action for membership

### 4. **Trainings & Exercises**
   - 6-image gallery showcasing various workouts
   - Motivational captions for each exercise type
   - Responsive grid layout

### 5. **BMI Calculator**
   - Interactive form with multiple input fields
   - Reference chart for BMI interpretation
   - Activity factor selection

### 6. **Meet Our Team**
   - 6 professional trainer profiles
   - High-quality trainer photographs
   - Name and role display

### 7. **Pricing Plans**
   - Three-tier pricing structure ($50, $150, $250/month)
   - Clear feature comparison
   - Individual CTA buttons for each package

### 8. **Footer**
   - Quick links and navigation
   - Company mission statement
   - Copyright information
